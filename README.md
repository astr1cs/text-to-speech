# Text to Speech

## 📝 Overview

**Text to Speech** is a web application built using **React.js** that converts written text into audible speech. Users can simply enter or paste any text, and the app will read it out loud using a natural-sounding voice. This app is great for accessibility purposes, language learning, and anyone who prefers to listen to content instead of reading it.

With a simple interface and a variety of voices to choose from, **Text to Speech** offers a seamless way to convert text into speech with just a click of a button.

🔗 [Live Demo](https://astr1cs.github.io/text-to-speech/)

## 🚀 Features

- **Text to Speech Conversion**: Input any text and listen to it being read aloud.
- **Multiple Voices**: Choose from different voices and languages for the speech output.
- **Adjustable Speech Rate**: Control the speed of the speech for personalized listening.
- **User-friendly Interface**: Clean, simple, and easy to navigate for users of all ages.
- **Responsive Design**: Fully functional on both desktop and mobile devices.

## 🛠️ Technologies Used

- **React.js**: A JavaScript library for building user interfaces.
- **Web Speech API**: Used for text-to-speech functionality.
- **CSS**: Custom styling for a responsive and clean design.
- **HTML**: For structuring the application.
